# @lodado/eslint-plugin-local-rules

Custom ESLint rules for the defects coding agents produce that still type-check: requests in
components, asserted payloads, unexplained skips and effects, clock and random reads while
rendering, FSD layer direction and more. The `@lodado/eslint-config` presets turn each rule on
at an explicit severity; installing the plugin alone enables nothing.

Rule list and severities: [eslint-setup skill](https://github.com/lodado/my-Vibe-Coding-Helper/blob/main/packages/vibe-coding-helper/skills/eslint-setup/SKILL.md#local-rules).
