# 디자인 준비자료 — 선택형 입력 양식

아는 부분과 이미 가진 자료만 제공한다. 빈칸은 `unknown`(아직 모름), `없음`은 자료가 없는
`none`이다. 공식 파일·링크를 주면 AI가 읽고 정리하며, 모든 섹션의 레이아웃·컴포넌트·토큰값을
직접 정할 필요는 없다. 이 양식은 필수 설문이 아니라 준비된 정보를 빠르게 전달하는 선택형
입력이다. 질문과 준비 종료 조건은 [discovery.md](./discovery.md)를 따른다.

## 1. 기획

- 디자인 대상/위치:
- 주 사용자와 사용 상황:
- 가장 중요한 이해·판단·행동:
- 반드시 들어갈 내용·기능:
- 실제 문구·데이터·이미지 위치:
- 알려진 섹션과 역할 (없으면 AI 제안):
- 영역의 순서·개수 변경 가능 여부:
- 유지할 부분·변경 금지:
- 언어·화면 크기·필요 상태:
- 필요한 결과물과 적용 위치:
- 가장 중요한 평가 기준·실패 기준:

## 2. 브랜드 자산·토큰

- 최신 기준 문서/Figma/라이브러리/토큰 파일:
- 우선할 원본·버전·적용 범위:
- 로고와 사용 가능한 변형:
- 폰트·굵기·라이선스·실제 언어 지원:
- 색상 역할·테마:
- 간격·타이포그래피·레이아웃·표면 규칙:
- 사용 가능한 제품 이미지·사진·아이콘·일러스트·모션:
- 절대 유지할 브랜드 특징:
- AI가 제안·조정해도 되는 범위:
- 없는 핵심 자산 처리: 대기 / 자산 없이 구성 / 승인된 예시 / 미정

자산의 세부 상태와 `provided`·`extracted`·`none`·`proposal-needs-approval`·`N/A` 구분은
[brand-intake.md](./brand-intake.md)를 사용한다. 값을 모르면 추측하지 않고 비워 둔다.

## 3. 대표 레퍼런스

전체 방향 자료와 특정 구성·동작 참고를 구분한다. 링크만으로 외형을 확인했다고 하지 않으며,
실제로 본 프레임·스크린샷·상태를 표시한다.

### R1

- 링크·Figma 프레임·첨부 이미지:
- 역할: 브랜드 기준 / 전체 분위기 / 구성 / 동작 / 피할 표현
- 적용 범위:
- 실제 확인한 화면·상태:
- 마음에 드는 관찰 가능한 특징:
- 가져오지 않을 부분:
- 기존 브랜드·목적과 충돌할 부분:
- 동작 참고 자료(상태/영상/설명):

### R2 (필요한 경우만)

- 링크·Figma 프레임·첨부 이미지:
- 역할:
- 적용 범위:
- 실제 확인한 화면·상태:
- 마음에 드는 특징:
- 가져오지 않을 부분:

## 4. 도구·작업 범위

- 참고자료 탐색 도구/MCP (확인된 것만):
- 결과 제작 도구·편집 환경:
- 출력 형식: 정적 시안 / 편집 가능한 디자인 / 인터랙티브 프로토타입 / 코드 / 기타
- 결과 적용 위치:
- 읽기 허용 파일·영역:
- 쓰기 허용 파일·영역:
- 별도 승인이 필요한 구매·외부 업로드·공개 배포:
- 방향 확정 후 섹션 구성과 세부 디자인을 AI에게 위임: 예 / 아니오 / 미정

비밀키·비밀번호·인증 토큰은 이 양식에 넣지 않는다. 공개 가능한 디자인 토큰값/파일과 구분한다.
도구의 존재는 실제 연결을 확인한
뒤에 사용하며, [art-direction.md](./art-direction.md)의 시각 확인 범위와
[section-composition.md](./section-composition.md)의 출처 기록을 함께 남긴다.

## 에이전트에 전달할 요청

이 자료를 읽고 디자인 결과를 바꿀 미결정 사항만 grill 방식으로 구체화해 주세요. 목적·필수 내용·
브랜드 처리·레퍼런스 해석·출력 범위를 합의한 뒤, 그 안의 섹션 구성은 여러 템플릿과 MCP 자료에서
직접 선택하고 지정 위치에 적용해 주세요. 이미 있는 사실을 다시 묻거나 모든 컴포넌트를 제가
고르게 하지 마세요. 유효한 기존 승인과 실행 요청이 있으면 반복 승인 없이 진행해 주세요.
