# Frontend Interface Design — compatibility entry

이전 이름으로 호출한 요청은 [Reference-Driven Figma Design](../reference-driven-figma-design/SKILL.md)을
읽고 그 capability gate와 실행 계약을 따른다. 상대 경로는 이 파일 기준이다.

최종 결과는 편집 가능한 Figma다. 이전 HTML/React 생성 workflow를 복구하거나 Figma write 권한
부족을 코드·정적 이미지로 우회하지 않는다. 구현 요청은 이 스킬 범위 밖임을 명시한다.
