# Start a design, not a template collection

Copy the five templates into a new authorized project directory. Keep stable IDs across them, or combine them while retaining the five logical artifact kinds.

- [Game design](game-design.md)
- [Flow](ux-flow.md)
- [Visual and feel](visual-and-feel.md)
- [Handoff and validation](validation-and-handoff.md)
- [Evidence log](reference-log.md)

The [worked example](../examples/merge-garden/game-design.md) is a synthetic proposal, not an observed successful game. Its [manifest](../examples/merge-garden/delivery.json) demonstrates shape and declared evidence only. Do not copy its choices blindly into another genre.

Populate the manifest according to the local [delivery schema](../schemas/game-delivery.schema.json). Mark incomplete templates DRAFT, not PLAN_READY. Actual required files must exist before structural validation passes.
