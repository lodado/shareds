# Technical handoff and validation

## Responsibilities

Input, simulation, rendering, UI, storage, analytics and platform ownership. Smallest playable slice; no unneeded engine.

## Event contracts

Event | trigger/payload | owner/consumers | run/request identity | duplicate/order handling | durable effect.

## Device and performance

Target device/browser/network/resolution; proposed budgets vs measurements; low-quality fallback preserving rules and cues.

## Experiments

X-ID | uncertainty | hypothesis | minimal test | observation | sample/device | proposed decision rule | change on failure | status/evidence.

## Metric definitions

Event trigger, numerator/denominator, cohort, follow-up window/timezone, exclusions, deduplication, privacy.

## Review dimensions

Rule correctness; flow; readability; actual feel/fun; business. Self-review, model review and human testing are not interchangeable.
