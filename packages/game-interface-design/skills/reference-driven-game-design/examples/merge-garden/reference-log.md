# 예제 근거와 검증 범위

이 예제는 독립 게임 스킬의 작동 형태를 설명하는 합성 제안이다. 실제 플레이 관찰, 사용자 승인, 유통 계약, Figma 편집, 성능 측정은 하지 않았다.

지적 참고는 패키지의 theory-to-decisions.md에 적힌 공개 책 자료다. 특정 게임의 화면·모델·음원·동영상 관찰 결과는 이 예제의 근거로 주장하지 않는다. 디자인 판단과 모든 튜닝 값은 proposal이다.

## source_trace.references

생산용 Figma 자산 없음. source gate 미실행이며 PLAN_ONLY에서는 해당 제작을 요청하지 않았다. 향후 FIGMA 요청에서는 실제 후보 탐색·권리 확인·import·비교가 필요하다.

## 기록

core loop→flow→feedback→handoff를 문서로 연결했다. 실제 검증 결과를 적을 수 있는 곳은 이후 실험 기록이다. 예제 manifest의 design_document evidence는 이 작성된 문서의 위치만 가리킨다.

planning: 문서 범위의 계획 준비. figma: not_requested. playable: planned. usability/fun: planned. business: not_run. user_acceptance: not_obtained.

열린 비차단 항목: 사업적 수요, 실제 physics tuning, 생산 아트, 목표 기기별 성능. 실제 구현/공개 출시는 모두 별도 검증이 필요하다.
