# 시각·손맛 — 제작 전 명세

## 선택한 잠정 방향

A는 무광 장난감 화분과 선명한 실루엣, B는 종이 그림자와 평면적인 도형이다. 동일한 플레이 상황에서 깊이 혼동과 제작 비용을 비교할 계획이다. Three.js의 재질 표현을 시험하기 위해 A를 잠정 선택했지만 실제 비교 화면이나 에셋은 아직 만들지 않았다.

배경은 플레이 물체보다 낮은 강조, 고정 정면에 가까운 카메라, 가로/높이 원 판정이 읽히는 투영으로 제안한다. 사선 카메라로 충돌 영역을 숨기지 않는다. 원형 물체 외형의 장식은 실제 hit area와 다르다는 점을 검증한다.

토큰은 text.primary, surface.overlay, action.primary, play.danger, focus.ring, motion.feedback의 의미 역할을 먼저 정의한다. 색/폰트 숫자는 아직 고정하지 않는다. 같은 색을 쓰더라도 play.danger와 menu.error는 별도 역할이다.

컴포넌트 범위는 ScoreHUD, NextSeed, PauseControl, DangerLine, ResultOverlay, PrimaryAction이다. pressed/disabled/focus 상태, 긴 한국어 문구, 짧은 화면을 검토한다. Figma 인스턴스를 제작했다고 보고하지 않는다.

## 자산·권리

이 예제에는 외부 아트·폰트·음원·모델이 없다. 임시 도형과 실제 디자인 요구를 구분한다. 추후 권리가 확인된 기본 기하/음원 또는 직접 제작 자산을 사용한다. 생산용 자산과 source gate 검증은 FIGMA/실제 제작 전 과제다.
