# Verification plan and evidence

Keep five domains separate: rule correctness; player-flow usability; visual readability; control/feel and enjoyment; business viability. A sixth optional domain is actual Figma artifact/readback correctness.

Select three high-risk hypotheses. For each record hypothesis, minimal experiment, participant/device/context, observation, proposed decision threshold, uncertainty and change on failure. Numbers are not universal benchmarks. Design a playable micro-slice early enough to test feel alongside core rules, not only after full art.

A useful observed session asks the player to act, not merely agree with a leading question. Watch how they start, where they hesitate, explain failure, change strategy and spontaneously replay. Distinguish requested replay from voluntary replay. Self-review and model review are not human participants.

Telemetry: each event has trigger, properties, run/session identity, deduplication, purpose and privacy. Define first meaningful action under actual rules. Count game_ready, run_start/end and replay only when helpful; no unnecessary every-frame tracking.

Metrics need numerator, denominator, exclusions, cohort, acquisition channel, observation window and timezone. Define calendar-day vs elapsed-day retention, completed follow-up window and distinct users. Short sample or lost follow-up → uncertainty, not a decisive win. Tutorial/ad-assisted runs must be included/excluded consistently.

Predeclare stop/iterate criteria for the experiment, not universal genre success rates. No D1/D7/eCPM benchmarks from memory without a scoped current source.

Report `not_run`, `planned`, `observed` with artifact/session evidence. Automated schema checks only validate structure and selected consistency conditions. Even real Figma screenshots/readback do not demonstrate player behavior, backend success or browser accessibility.

A required in-scope blocker cannot disappear into "future improvement" while marking that scope ready. Unrun optional research can coexist with a completed design plan when clearly labeled.
