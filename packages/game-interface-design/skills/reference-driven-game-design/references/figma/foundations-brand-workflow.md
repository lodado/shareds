# Pilot foundations and source preflight

Preserve or resolve approved art/brand authority. Follow [edit contract](edit-contract.md) and [source gate](component-source-gate.md). Do not claim a token table is a created design system.

After explanation and any review-wait, import one representative candidate into the isolated work area. Verify actual IDs, editable child layers, component source/links, available fonts, variable/style bindings and real-state mobile fit. Record retention/cleanup; delete only your scoped probe when safe.

Required live-library linkage cannot silently become a detached snapshot. Source failure holds adoption/expansion, not independent game planning.

Define only pilot foundations: type, semantic color, spacing/layout, elevation, icon and motion roles. Distinct meanings remain distinct even if values currently match. Record contrast/focus/non-color/touch/reduced-effect constraints without claiming a specific standard was tested unless it was.

In Figma mode readiness needs actual Variables, Styles, Components and bound consumers. Re-read representative bindings. Test temporary propagation only on authorized local working tokens, restore and reread; otherwise mark unverified. Never mutate a shared library as a probe.
