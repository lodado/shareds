# Direction and targeted comparison

## 1. Direction

Reuse locked art. If open, compare two substantive options on one representative game state. Keep content, state and viewport equal. Choose shape/material/camera/readability strategies, not color-swapped copies.

## 2. Selection

Explain hypotheses and source rationale before writes. Run required source comparisons separately; alternatives never waive the source gate. Evaluate gains, losses and player task fit. Agent choice is a proposal unless delegated; never invent user acceptance.

## 3. Targeted feedback

Record `frame/node → observed issue → player impact → change → preserve`. Compare before/after with the same content, viewport and state. Fix only relevant nodes; no entire-game regeneration for one HUD alignment problem. If the cause is an unreadable rule or spatial relationship, reopen the earlier decision.
