# Evidence → reference → adaptation

Unlike the parent package, this independent fork requires no private/local taxonomy dictionary. An optional user-local dictionary is only search vocabulary, not proof of a screen or editable source. Never fabricate missing definitions or redistribute its text.

Search by player decision + UI role + state/device. Separate observed game/screens, inferred rationale and actual editable assets. Record URL/date/version, inspected state/width, component key/ID, rights and import/link status. Only tool-returned identifiers count.

Use internal fit first, then [component source gate](component-source-gate.md) for actual gaps. Composition examples do not automatically authorize art reuse or copied visual identity.

For pilots compare observed reference and actual readable capture at matching task/state/viewport. Record differences in content, material, language and intended play behavior. Verify hierarchy, field visibility, control placement, clipping and density—not merely node counts.

Keep the log's `source_trace.references` rows with source, selection_reason, role, applied target and uncertainty. Link their evidence IDs from the game manifest. A gate pass verifies the inspected source decision, not usability or fun.
