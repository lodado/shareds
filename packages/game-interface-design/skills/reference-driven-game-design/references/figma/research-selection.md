# Bounded source selection

Inventory approved internal assets first. Verify candidate task/role, content, state, mobile width and rights. A library name or thumbnail is insufficient. The correct internal source may win after comparisons.

When a gap requires external comparison, use two distinct sources in equal conditions through [component source gate](component-source-gate.md). Stop after enough valid evidence supports the decision; one purposeful pass per source class, then report thin sourcing honestly.

Preserve visual-system ownership. External screens may contribute composition, not an arbitrary mixture of fonts, color, radius and shadows. A template is a starting point, not a license to omit necessary game controls.

Source preflight must prove import/copy, editable descendants, font availability, bindings and main-component linkage where required. Failed imports do not authorize a different ownership model without approval.
