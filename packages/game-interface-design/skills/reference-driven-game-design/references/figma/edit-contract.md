# Preserve/change contract

For each area select ASSEMBLE, LOCALIZE, FIDELITY, RESKIN or REDESIGN, with explicit preserved structure, behavior, art, tokens and content. A request to improve game UI does not release an existing source-fidelity constraint.

Use an authorized duplicate/work area. Preserve source and originals; do not detach published instances indiscriminately. Record linked instance, copied frame and local derivative truthfully. No changes to an external library to test a consumer.

Judge Source, Fidelity, Content and Layout independently. Missing source is not permission for screenshot redraw. Separately authorized original/derivative design must be called that, not source-faithful reconstruction. A Figma frame holding a flattened screenshot is not editable game UI.
