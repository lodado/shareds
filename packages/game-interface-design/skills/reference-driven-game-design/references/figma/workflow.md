# Local Figma execution path

These are local copies/adaptations of source contracts. No frontend plugin is loaded. Apply only in FIGMA mode. Game planning has its own legitimate completion state in [game delivery](../game-delivery.md).

1. Read [request](request-contract.md), [edit scope](edit-contract.md), and [HCI](hci-wireframe-workflow.md). Verify actual provider tools/companion guidance, permissions and target. No write or test import before wireframe explanation and explicit review-wait, when present.
2. Read [source gate](component-source-gate.md), [source mapping](taxonomy-reference-workflow.md), [selection](research-selection.md) and [foundations](foundations-brand-workflow.md). Build only from verified editable sources; keep source/rights/linkage distinct.
3. Read [composition](figma-composition.md), [direction](visual-direction.md) and [critique](critique-refinement.md). Pilot 1–3 game screens/states before expansion, re-open at reading size and fix local issues.
4. Read [prototype](prototype-workflow.md) and [delivery](delivery-contract.md). Preserve reactions, connect only scoped behavior and reread changed reactions. Never count connections as game simulation, backend or playtest proof.

Game translation of inherited vocabulary: product emphasis means the readable game field and consequential controls; sections mean HUD/field/overlay regions; activation means first meaningful play; true product assets means actual approved game content where required. No generic SaaS layout implied.

The three retained reference files contain legacy log field names such as `source_trace.references`. In this fork they map to the same-named nested trace section in the Reference Log, and evidence IDs in the game delivery manifest—not to an unavailable upstream schema. Figma state words map to `readiness.figma`; they never override `readiness.planning`.

Provider guidance is conditional on the actual connected tool. A reference to a named Figma provider is not proof of installation; use its documented equivalent if a different authorized provider offers the required capability. No live execution is claimed by this package.
