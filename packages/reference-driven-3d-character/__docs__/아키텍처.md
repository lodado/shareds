# 레퍼런스 기반 3D 캐릭터 스킬

하나의 `skills/reference-driven-3d-character/SKILL.md`를 Claude Code와 Codex에서 함께 읽는다. 핵심 절차는 진입 문서에, 설계·동작·검증의 조건부 설명은 세 참고 문서에 둔다. 새로운 래스터 설계안에는 가용한 `imagegen` 지침과 도구를 사용하고, 요청된 세부 인터뷰에는 설치된 `grill-me`를 사용할 수 있다. 해당 기능의 부재를 알리며 자동 설치하지 않는다. 기존 설계 재사용이나 국소 수정에 이 도구들을 필수로 요구하지 않는다.

스킬은 자료와 용도에서 형태·변형·동작 요구사항을 도출하는 방법을 제공한다. 모델 생성기나 상태 관리 엔진은 포함하지 않는다. 실행 에이전트가 실제 프로젝트의 도구를 확인하고 원본을 보존하며 결과를 만든다. 작은 수정은 유효한 선행 결정을 재사용하고 영향받는 단계만 다시 검증한다.

구도·상세 영역·제어 방식은 정체성, 구조적 불확실성, 변형, 접촉에서 도출한다. 신체 부위 목록이나 종별 레시피는 본문의 실행 규칙으로 넣지 않는다. 신규·큰 재설계의 시각 설계안과 실제 3D 시제품은 각각 확인하며, 명시적 위임과 유효한 기존 승인은 그 범위에서 재사용한다. 확인 기록은 기존 프로젝트 노트와 대화를 사용한다.

`scripts/skill-contract.test.mjs`는 단일 진입점, 두 호스트의 등록, 로컬 문서 링크를 확인한다. `evals/scenarios.md`는 실제 작업 판단을 평가하는 별도 자료다. 정적 검사 통과와 에이전트의 수행 품질은 다른 주장이다. 실행 평가 결과는 해당 입력·스킬 버전·환경·산출물·한계를 기록한다.
