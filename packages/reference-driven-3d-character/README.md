# reference-driven-3d-character

레퍼런스를 보고 편집 가능한 3D 캐릭터를 설계·제작·수정하는 스킬이다. 특정 동물의 생성 코드 대신 형태, 부착, 변형, 접촉을 판단하는 원리와 단계별 검증 방법을 제공한다.

## 사용

저장소의 로컬 마켓플레이스를 추가한 뒤 설치한다. 공개 원격 마켓플레이스에서 사용하려면 이 패키지가 포함된 리비전이 먼저 배포되어야 한다.

```text
/plugin marketplace add /absolute/path/to/my-Vibe-Coding-Helper
/plugin install reference-driven-3d-character@my-vibe-coding-helper
```

Codex용 manifest도 같은 `skills/` 디렉터리를 가리킨다. 실제 플러그인 설치·검색 지원은 사용하는 호스트에서 확인한다. 이 패키지 추가 자체가 전역 설치를 수행하지는 않는다.

```text
$reference-driven-3d-character
이 턴어라운드를 참고해서 Blender에서 편집 가능한 캐릭터를 만들어줘.
게임의 고정 카메라에서 실루엣이 읽혀야 하고, 대기와 걷기 동작이 필요해.
구조를 먼저 설명하고 모델링, 리깅, 동작, 내보내기를 각각 확인해줘.
```

```text
$reference-driven-3d-character
이 캐릭터의 얼굴 부착물이 떠 보여. 몸통과 색상, 기존 동작은 유지하고
부착 관계만 고쳐줘. 옆면과 고개를 돌린 포즈에서도 확인해줘.
```

## 진행 방식

실행 환경과 원본을 확인하고, 사용 목적과 자료 우선순위를 정리한다. 신규·큰 재설계는 먼저 시각적 설계안을 보여주고 확인받는다. 그다음 구조를 설명하고 실제 3D 시제품을 만들어 두 번째로 확인받는다. 요청에 포함된 경우에만 상세 리깅과 동작으로 확장한다. 마지막으로 원본 재개방, 필요한 내보내기·재임포트, 요청한 소비 환경을 따로 확인한다.

구도와 확대 부위는 정체성, 숨겨진 입체 구조, 연결, 변형, 접촉의 불확실성에서 선택한다. 특정 신체 부위나 시점 수를 필수로 두지 않는다. 새로운 래스터 설계안이 필요하면 설치된 `imagegen` 지침과 기본 내장 도구를 사용한다. 생성된 격자는 실제 메시의 와이어프레임으로 취급하지 않는다.

간단한 외형 예시와 상세 모델 시트는 구분한다. 상세 시트 요청에서는 전체 형태·보완 시점·구조 확대에 필요한 정보를 먼저 정하고, 각 컷을 읽을 수 있게 배치한다. 캐릭터 디자인 참고와 시트 구성 참고는 역할을 분리한다. 질감이나 해상도를 높이는 것으로 빠진 구조 정보를 대체하지 않으며, 한 장에 담기 어려우면 필요한 보조 시트를 제공하거나 제약을 알린다.

세부 선택은 보이는 결과를 놓고 중요한 것부터 하나씩 묻는다. 요청된 `grill-me`가 설치돼 있으면 원문을 읽고 사용하며, 없으면 그 사실을 알리고 같은 목적의 질문을 직접 한다. 이미지 도구가 없을 때는 필요한 시각 단계의 미완료와 가능한 대안을 설명한다. API 결제나 도구 설치로 자동 전환하지 않는다.

작은 수정은 유효한 선행 결정을 재사용한다. 정적 모델에는 리깅과 보행을 추가하지 않는다. MCP가 없어도 허용된 CLI가 동작하면 사용할 수 있다. 실행 환경이 없으면 스크립트와 한계를 제공하되 실제 모델 생성·렌더·재생을 완료했다고 보고하지 않는다.

충분한 기존 도면과 해당 버전의 승인은 재사용한다. 작은 수정에 전신 설계안을 다시 요구하지 않는다. 사용자가 시각적 결정을 명시적으로 위임하면 확인 대기를 생략할 수 있지만, 에이전트의 판단을 사용자 승인으로 기록하지 않는다.

## 검증 범위

```bash
pnpm --filter @lodado/reference-driven-3d-character-plugin test
pnpm --filter @lodado/reference-driven-3d-character-plugin lint
```

패키지 검사는 스킬 진입점, 호스트 manifest, 마켓플레이스 항목, 로컬 문서 링크를 확인한다. 에이전트의 실제 행동이나 미감을 인증하지 않는다. 실행 평가에서는 실제 입력·환경·스킬 리비전·결과물·검증하지 못한 항목을 별도로 기록한다.

범용 모델 생성기, 자동 설치, 새로운 MCP 서버, 학습 파이프라인, 게임 시스템은 포함하지 않는다. Blender가 모든 호스트에 설치되어 있다고 가정하지 않으며 외부 유료 서비스나 자료 업로드 권한을 부여하지 않는다.
