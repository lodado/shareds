# Korean voice: contextual observations

Use this with the analysis guide, not as a default Korean style. Extract from PROFILE only. Every observation needs evidence (snapshot + document:block), a trigger, counterexamples and confidence, or `insufficient_evidence`. These categories refine existing dimensions, not a new author stereotype.

| Observation        | What to inspect                                                                                                      | Writing decision                                                                                    |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| register_switch    | Where `-다`, `-습니다`, `-요`, `-죠`, `-네요` alternate: explanation, reported information, direct address, reaction | Choose register by the current clause's role, not a whole-article quota                             |
| reader_distance    | `여러분`, `우리`, `이웃님`, omitted address, questions inviting recognition versus answers                           | Reproduce the relationship where supported, without pretending the reader has a specific experience |
| connective_endings | `-는데`, `-지만`, `-고`, `-니까`, omitted connectives and short afterthoughts                                        | Preserve the source claim's logical relation while adapting clause linkage                          |
| sentence_finish    | Full predicates, noun fragments, unfinished asides, rhetorical questions                                             | Distinguish deliberate rhythm from damaged extraction or an image caption                           |
| reaction_palette   | Surprise, light amusement, sympathy, self-directed jokes; `ㅋ`, `ㅎㅎ`, `ㅠ`, `^^`, `~`, ellipses                    | Use only in the observed context and if the supplied stance supports the reaction                   |
| aside_function     | Parentheses explain, qualify, contradict playfully, or address the reader                                            | Select the function, not a copied parenthetical sentence                                            |
| lexical_register   | Native/Sino-Korean terms, colloquial shortenings, English glosses, ordinary repeated connectors                      | Preserve necessary terms; do not import source-topic vocabulary or upgrade intensity                |
| self_reference     | Experiential `저도`, explanatory `제 생각`, inclusive `우리`, omitted narrator                                       | First-person experience requires a supplied experience; author biography is not permission          |
| layout_rhythm      | Short visual lines, multi-line sentences, paragraphs around images, section labels                                   | Use real text structure; do not invent images, image observations, headings or conclusions          |

Title craft is separate: inspect topic names, noun phrases versus sentences, separators, emotional framing and their genre limits. The blog/site title and a file stem are not article-title evidence. A rhetorical heading must not introduce a stronger factual claim.

## Meaning boundaries

Changing `-습니다` to `-요` can preserve a claim. Changing `가능할 수 있다` to `확실하죠` changes certainty. Likewise `-다고 하네요` attributes a report: do not manufacture hearsay, sources or consensus merely because the author uses reported speech. An aside cannot add an unsupplied opinion or experience. Use an informative alternative when a style device needs missing content.

Common particles, connectors and short emoticons are not inherently distinctive copied passages. Do not ban them merely for occurring in the source, and do not force them into every paragraph. Treat counts as diagnostic context, not a target similarity score. Keep genuine author-supported quirks when a generic humanizer would erase them.

## Observation example (synthetic, not author evidence)

If independent PROFILE examples repeatedly switch from a factual explanation to a light reader-facing question, record that transition with exact evidence and its exceptions. A new draft may use an answerable question about an already supplied condition. It may not claim a reader tried the product, invent a personal anecdote, or intensify a tentative benefit. If only one example exists, keep the observation weak.
