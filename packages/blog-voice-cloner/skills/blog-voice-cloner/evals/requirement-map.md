# Requirement-to-observation map

This map covers all 20 numbered requirements and the subsequent recent-30-day storage design. **Mapped is not the same as proven.** Mechanical checks are reproducible, host behavior has bounded smoke evidence, and missing human/real-author evaluation remains explicitly unverified.

Reproduce individual results with `python3 evals/verify_requirements.py` from the skill directory. `evals/requirement-observations.json` records every executed test ID and observed outcome, not just totals. All cited `test_*` names below resolve to that file. No statistical or stylistic quality score is computed.

## What the feedback loop actually proves

The implementation now handles the five independently reproduced defects: duplicate confidence inflation, broken snapshot evidence IDs, text/HTML re-interpretation, inline-code sentence fragmentation and unbounded aggregate overlap work. Regression tests execute those behaviors and report passed. That is a concrete functional improvement, not inspection alone.

The saved B→D writing comparison reduces two copied sample phrases from one each to zero and question marks from three to zero while keeping TTL 60 present. This establishes only a bounded anti-copying observation, not broad style preference or semantic correctness. Independent semantic review evaluates the actual demo separately. A stronger claim that the system writes better in a real influencer's voice requires the missing real corpus and human blinded evaluation. Overall traceability remains **partial in evidence**, despite complete enumeration of the requested sections.

## Independent outcome observation

The separate brief-only semantic reviewer returned PASS on the actual demo: 7 output units, 10 atomic claims, 0 unsupported claims, 0 actionable findings. It inspected neither the author corpus nor the profile. The report includes clause-level support and modal/negation/causality/condition checks. This closes the semantic feedback loop for that bounded sample, not for all future articles.
