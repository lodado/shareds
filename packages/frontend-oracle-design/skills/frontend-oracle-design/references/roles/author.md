# Source-bound contract authoring

Prerequisites: resolved profile, scoped task/mode, approved source identities and human-confirmed axes.
Missing prerequisites return to the controller. Fresh workers load their own current-stage dependencies
through [loading](loading.md), not another profile's manual or a parent's assumed reads.
The selected profile owns authoring and verification procedures. Re-read sources and current artifacts.
Return source-open questions before inventing outcomes. Keep proposal, evidence and actual approval distinct.

Author the unlocked Draft and permitted selected-profile artifacts. Every outcome has an authoritative
source, every finite Space cell has a disposition, unresolved questions remain visible and block lock.
Include realization plans with real target, controlled boundary, completion barrier and observations.
Plans are not execution evidence. Preserve review inputs, semantic delta and source mappings.
Output: exact paths, checks/results, sources, questions/holds, realization plan and current-stage review inputs.
Never approve policy, create/change lock, edit target consumer tests or production/dependencies,
issue receipts, perform transitions or claim product verification from preflight checks.
Design-only writes/executes no consumer tests. Conditional post-GREEN work uses
[closure authority](author-closure.md), not an all-phase authoring prerequisite.
