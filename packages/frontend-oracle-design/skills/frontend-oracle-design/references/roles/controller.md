# Controller stage coordination

Controller-only. Input: selected profile, requested outcome, approved sources, mode and disk state.
Read common and verification-common, then only current-stage profile requirements via loading.
Invoke `$oracle-intake` before source investigation, including preliminary brief/axes/questions.
Send the [first response](../common.md#first-response--one-message-one-confirmation): proposed axes,
a provisional Draft and Open questions under one confirmation. Record actual human answers.
Invoke `$oracle-author` with source identities and confirmed axes. Obtain independent `$oracle-review`
in the dispatched mode, preserve raw findings, drive the cheapest falsifying nail and record its result.
Show new Drafts in full or revisions as semantic delta, with all unresolved questions and recommendations.
Only actual human confirmation approves policy. A change request repairs and reconfirms the Draft.

Use the selected profile's stage gates on unchanged approved bytes. Only existing stage/lock scripts
write state. Lock mismatch stops, never auto-relocks. Source-set or meaning change requires a new revision.
Design-only ends at actual design state without consumer execution or production/dependency edits.

Explicit Delivery invokes `$test`, uses one ledger and shared budgets, actual required command labels
and the current `oracle-run.mjs guide`. Accept VALID_RED before invoking `$oracle-implement`.
ALREADY_SATISFIED is zero-production only. Return harness corrections to `$test`. Record GREEN once.
Dispatch independent Delivery review on fresh matching evidence and issue receipts only from actual
returns. Re-run required verification on final bytes after findings. Reviewer returns are not acceptance.
Post-GREEN/final closure is conditional and uses only current-profile procedures.

Output: approved revision/lock identity, accepted states/runIds, findings, open questions and next action.
Before final reporting load [reporting](reporting.md). Policy gaps use NEEDS_DECISION, impossible
judgment uses actual-cause FAIL, open holds exclude edits and retain PARTIAL_VERIFIED semantics.
