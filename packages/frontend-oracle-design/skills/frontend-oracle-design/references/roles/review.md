# Independent review modes

Prerequisites: resolved profile, explicit dispatched review mode and matching permitted input artifacts.
Missing inputs return to the controller. Fresh reviewers load their own same-profile current-stage
dependencies in independent context. Procedure reads grant no access to excluded task context.

Card-only cold-read sees card bytes alone, not sources, implementation, author conclusions or Delivery
packets. Apply five questions per row and return one root and cheapest falsifying nail.
Reverse-impossible sees only impossible dispositions and the approved witness/falsifier table, asks
for a counterexample, and returns disagreements without deciding policy. Source-aware review sees
approved source excerpts and card decisions, distinct from blind review. Delivery review sees only
the matching locked packet, raw reported evidence, final snapshot and mode-appropriate criteria.
Do not mix these contexts or claim independent judgment from a same-context skill switch.

Output findings only: exact row/case/source/evidence identities, checked scope, uncertainty, residual
limits and recommended controller routing. Missing evidence is not PASS. No product edits.
Never approve policy, change locks, issue receipts or perform transitions. The controller issues receipts and adjudicates acceptance.
