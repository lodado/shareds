# Controller verification and final report

Controller-only, load at reporting, not every role entry. Check artifacts before claims:

1. Header lists only actually read nodes, reconciled against tool calls.
2. Execution claims cite actual ledger runId, label, exit and grade once each, never fabricated before init.
3. Cold-read root, falsifying nail and observed result exist in the journal, not just a plan.
4. Recorded status agrees with `oracle-run.mjs status --json` and `--check-report` acceptance.

Lead with actual state and blocker. Report outcome, changed paths/rows, source/lock hashes, fresh
verification, independent findings, shared budget use and residual limits. Print applicable architecture,
design confirmation, visual QA and High hardening fields only when relevant, not bare N/A padding.
Design-only reports approval/stage without consumer-test claims. IMPLEMENTED_GREEN is not REVIEW_VERIFIED.
Use selected-profile reporting requirements to describe verification precisely. Plans, labels, file
creation, scanner observations and browser observations cannot be promoted to PASS. Open holds and
pending visual evidence retain their actual resumable meanings. Any artifact disagreement wins over prose.
