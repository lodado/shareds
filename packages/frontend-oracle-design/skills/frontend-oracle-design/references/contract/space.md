# Contract finite full-product Space

`oracle.md` owns explicit finite dimensions, values, constraints, revision and dispositions using the
existing card syntax. Coverage is `full-product`, never silently t-way or a list-specific default.
The raw Cartesian candidate cap is **100000**, checked before exclusions. Over-cap scope requires an
explicit approved rescope, never truncation, sampling or a hidden switch to reduced coverage.

Use the existing `oracle-space.mjs` / `oracle-frames.mjs` full-product paths to enumerate stable case IDs.
Distinguish raw candidates, generated frames and executable cases. Each current frame ID occurs once
with a source-backed disposition and row/scenario mapping. Reject missing, duplicate, extra, stale or
revision-mismatched IDs. Changing dimensions/values/constraints regenerates IDs and invalidates old
dispositions/evidence. A count alone does not establish coverage.

Unknown combinations remain included until decided. `needs-decision` and `needs-evidence` are unresolved
and block lock. Investigate evidence gaps, ask policy questions through the controller. Impossible/excluded
cases require approved constraints and a falsifiable witness/reason, not an agent's convenience.
Every required executable case has source-approved expected outcomes and a real realization plan.
Finite paths represent async/order behavior where relevant, not only static combinations.
Scope omissions, abstraction choices and residual limits remain explicit, no claim Space equals reality.
