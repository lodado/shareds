# Contract GREEN and independent Delivery review

Self-feedback and required checks run on final locked snapshot. Actual case reporter IDs cover all
required executable cases, applicable type/property evidence follows [requirements](requirements.md).
Missing/failing evidence is not GREEN. Bounded simplification re-verifies final bytes within product budget.
After GREEN dispatch independent [review](review.md), using mode-appropriate raw packet/criteria.
High retains mutation kill/revert/re-GREEN, independent two-sample review and required post-review reruns.
Reviewers return findings only, controller records actual receipts/acceptance through existing runtime.
Rerun required checks after findings, never duplicate GREEN transition or report old snapshots as current.
Visual journey obligations remain applicable. Browser/scanner observations are pending/non-verifying,
certified visual evidence uses the supported trusted node-test producer. Explicit external QA remains
opt-in. Unresolved/declined visual evidence without locked source-backed non-application ends resumably
at IMPLEMENTED_GREEN, not REVIEW_VERIFIED. Open holds retain PARTIAL_VERIFIED with no held-row edits.
Final report uses actual state/runIds and `formalVerification: not-performed`, finite coverage and limits.
